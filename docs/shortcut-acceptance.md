# 键盘操作与验收清单

这份清单覆盖素笺的文档命令、编辑区、文件导航、菜单和快捷键设置。`Mod` 在 Windows 和 Linux 表示 `Ctrl`，在 macOS 表示 `⌘`。`Alt` 在 macOS 对应 `Option`。表中的“待设置”表示命令可在 **设置 → 快捷键** 分配组合键。方向键、剪贴板和输入法等平台约定以及按位置工作的单键交互列在后文。

## 调研依据

## 写作与 Markdown 格式

格式命令面向即时编辑、源码和分栏左侧的编辑区，选区和光标决定操作目标。阅读模式、分栏预览区、文件树和搜索输入框中的同一组合键不应修改正文。工具栏、命令面板和快捷键应调用同一编辑动作。验收时检查渲染和保存后的 Markdown，并用撤销确认一次触发只执行一次。

行内格式验收覆盖标题、普通段落、引用、无序列表、嵌套列表、有序列表、任务列表和表格。另测局部单词、正反选区、边缘空白、已有格式和跨块选区。围栏代码有自己的复制与语言操作，阅读区域保留复制与导航。[行内格式实测范围](desktop-interaction-acceptance.md#正文位置与操作交叉验证)

| 功能 | Windows / Linux | macOS | 预期与检查点 |
| --- | --- | --- | --- |
| 正文段落、一级至六级标题 | `Ctrl+0`、`Ctrl+1` 至 `Ctrl+6` | `⌘0`、`⌘1` 至 `⌘6` | 当前文本块变为段落或指定级别，保留正文。用已有标题升降级并转回段落，核对大纲与磁盘内容。两份文档打开时仍然编辑当前文档。 |
| 加粗、斜体、下划线 | `Ctrl+B`、`Ctrl+I`、`Ctrl+U` | `⌘B`、`⌘I`、`⌘U` | 对选区应用相应格式。用单独光标与正向、反向选区验证范围、续写位置和撤销。 |
| 删除线 | `Alt+Shift+5` | `Ctrl+Shift+反引号` | 给选区添加删除线并保留选中文字。 |
| 行内代码 | `Ctrl+Shift+反引号` | `⌘+Shift+反引号` | 将选区变为行内代码，单独光标可输入代码内容。 |
| 链接 | `Ctrl+K` | `⌘K` | 打开链接输入，保留选区作链接文字，取消回到原编辑位置。 |
| 本地图片 | `Ctrl+Shift+I` | `⌘+Ctrl+I` | 打开文件选择，选择后插入图片引用，取消时正文维持原样。 |
| 代码围栏 | `Ctrl+Shift+K` | `⌘+Alt+C` | 插入围栏并保留选中文本，光标进入块内。用选中的代码行检查源码中的正文没有被删除。 |
| 块公式 | `Ctrl+Shift+M` | `⌘+Alt+B` | 插入块公式，选区可作为公式内容。 |
| 引用 | `Ctrl+Shift+Q` | `⌘+Alt+Q` | 对光标所在或选中的文本添加引用格式。 |
| 有序列表、无序列表 | `Ctrl+Shift+[`、`Ctrl+Shift+]` | `⌘+Alt+O`、`⌘+Alt+U` | 将正文转换为对应列表，检查列表标记、已有文本和后续回车。 |
| 表格 | `Ctrl+T` | `⌘+Alt+T` | 打开行列输入，确认后在编辑位置插入可渲染的 GFM 表格。 |
| 增加、减少缩进 | `Ctrl+[`、`Ctrl+]` | `⌘[`、`⌘]` | 按当前 Markdown 结构调整缩进。列表、代码和普通段落分别用光标与选区验证。 |
| 任务列表、分隔线、高亮、上标、下标、Mermaid、目录、脚注 | 待设置 | 待设置 | 可用工具栏或命令面板插入对应结构，保存后核对语法及渲染。 |

Typora 还提供逐级升降标题、清除格式、选词、选单元格和删除表格行的独立按键。验收素笺时，标题升降通过直接指定级别，表格行列通过表格工具和上下文菜单操作。窗口缩放使用平台菜单的加号与减号。 [Typora 快捷键](https://support.typora.io/Shortcut-Keys/)

## 段落、列表、表格与围栏

| 焦点位置 | 按键 | 即时编辑 | 源码及分栏编辑区 |
| --- | --- | --- | --- |
| 普通段落 | `Enter`、`Shift+Enter` | 新建段落或在当前段落内插入可保存的 `<br>`。 | `Enter` 延续 Markdown 文本结构，`Shift+Enter` 按源码换行。显式硬换行可直接输入 Markdown 或 `<br>`。 |
| 普通段落 | `Tab`、`Shift+Tab` | 单独光标插入可保存的空白或减少行首缩进。 | 缩进或减少当前行或选区内各行的缩进。 |
| 列表、任务、引用 | `Enter`、`Backspace` | 回车续项或续写引用，空列表项可以退出当前层。退格按当前位置删除内容。 | 回车延续 Markdown 标记，任务新项为未勾选，空项退出当前层。标记边缘退格按 Markdown 结构退回。 |
| 输入无序列表标记 | `*`、`-` 或 `+` 后按空格 | 在段首开始列表并把光标放在第一项正文。引用内和列表内按所在层级开始列表。围栏代码、行中和转义符后的字符按文字输入。 | 保留输入的 Markdown 标记。分栏在预览区呈现列表。 |
| 列表与任务 | `Tab`、`Shift+Tab` | 将当前项或选中的同级项向内移动，或把嵌套项提升一级。顶层项反缩进保留列表结构。 | 保留外层引用、列表标记宽度、续行和子列表后移项。顶层项反缩进保留列表结构。 |
| 表格 | `Tab`、`Shift+Tab`、`Mod+Enter` | 在单元格之间前进或后退，末格向前增加一行。`Mod+Enter` 在当前行下面插入一行并定位到同列。方向键可以在单元格和相邻段落间移动。 | 按源码行编辑，`Mod+Enter` 是源码插空行。管道符和表格分隔行由源码处理。 |
| 代码围栏 | `Enter`、`Tab`、`Shift+Tab`、`Backspace` | `Enter` 在块内换行。单独光标 `Tab` 插入制表符，选中代码时按四列缩进涉及的行。`Shift+Tab` 反缩进。非空块首字符前的退格保留围栏。 | 编辑围栏内容时按四列缩进或反缩进代码，保留外层列表或引用的缩进。 |
| 离开编辑区 | `Esc` 后 `Tab` 或 `Shift+Tab` | 让下一次 Tab 转移焦点，验证编辑区可以仅用键盘离开。 | 同样支持退出，`Esc` 也可简化多选区。 |
| 代码语言选择 | `↑`、`↓`、`Enter`、`Esc` | 聚焦语言搜索后移动候选，确认语言或取消并返回。保存后核对围栏语言和代码文本。 | 直接编辑围栏开头的语言标记。 |

### 反缩进和反向移焦点

在每个块中分别放置单独光标与选区，按 `Shift+Tab` 后核对编辑焦点、选区、块结构与保存后的 Markdown。即时编辑的表格使用单元格导航，源码与分栏编辑区依据 Markdown 结构处理。

| 当前位置 | 即时编辑预期 | 源码与分栏编辑区预期 |
| --- | --- | --- |
| 标题 | 保留标题级别、编辑焦点和当前选区。数字快捷键控制标题级别。 | 只处理源码行首缩进，保留 `#` 标记。 |
| 无缩进普通段落 | 保留正文和编辑焦点。 | 保留行内容和编辑焦点。 |
| 已缩进普通段落 | 去掉一级行首空白。 | 减少当前行或选中行的缩进。 |
| 顶层无序、有序及任务项 | 保留当前项的列表标记与层级。 | 保留当前项的列表标记与层级。 |
| 嵌套列表、同级多项选区 | 向外提升一级，连同子项。 | 向外提升一级，保留外层引用、同级选区及续行。 |
| 表格第一格 | 保持在第一格。 | 根据行首缩进处理管道符所在行。 |
| 表格中间、末格 | 退回前一格。跨行时到上一行最后一格，表体首格可退到表头末格。 | 根据行首缩进处理管道符所在行。 |
| 围栏代码 | 对当前代码行或选中行反缩进，保留围栏。 | 将代码行反缩进至多四列，保留围栏和外层容器缩进。 |
| 按 `Esc` 后再按 `Shift+Tab` | 反向转移编辑区焦点。 | 反向转移编辑区焦点。 |

素笺在顶层列表保留 `Shift+Tab` 的结构操作边界。要结束列表，可在空项按 `Enter`，也可在首个列表项文字开头按 `Backspace`。即时编辑在后续项开头按 `Backspace` 时并入上一项。这一行为按本轮讨论保留。

Windows Electron 的即时、源码和分栏桌面回归已通过。测试使用真实按键检查光标、反向选区、表格跨行、列表父子项、保存后的标记及 `Esc` 后的反向移焦点。

## 文本与剪贴板

| 操作 | 默认按键 | 预期与检查点 |
| --- | --- | --- |

| 复制 Markdown | `Mod+Shift+C` | 在编辑区复制选区对应的 Markdown，无选区时复制当前文档。阅读区有选区时复制可见文字。 |
| 复制富文本、HTML 源码、纯文本 | 待设置 | 有选区时复制选区，无选区时复制整篇。核对剪贴板类型。 |
| 按字符、单词、行、页移动和选择 | `方向键`、`Shift+方向键`、`PageUp/PageDown`。Win/Linux 用 `Ctrl+←/→` 按词移动、`Home/End` 到行边界、`Ctrl+Home/End` 到全文边界。macOS 用 `Alt+←/→`、`⌘←/→`、`⌘↑/↓`。 | `Shift` 扩展选择。检查窄窗口自动折行、段落首尾及 Unicode 文本边界。 |

源码编辑器还提供 `Alt+↑/↓` 移动行、`Alt+Shift+↑/↓` 复制行、`Mod+Alt+↑/↓` 加光标、`Mod+Shift+反斜杠` 跳转匹配括号等文本操作。编辑器附带的按键以实际模式和当前分配为准，可在回归时按 [CodeMirror 默认键位](https://codemirror.net/docs/ref/#commands.defaultKeymap) 检查。即时编辑中的原生输入行为以平台文本约定为准。

## 自定义快捷键

在 **设置 → 快捷键** 搜索动作，点 **更改**，按下组合键或在输入框填写，再点 **保存**。动作有自定义值时可点 **恢复默认**。未分配默认键的命令恢复后回到待设置状态。命令面板和带键位的工具栏入口显示当前有效键位。

| 验收场景 | 预期 |
| --- | --- |
| 修改标题、行内格式或块格式 | 新键位在三个编辑模式生效，旧键位停止触发该命令。阅读、文件树、查找输入和弹窗保持原有行为。 |
| 修改应用菜单命令 | 修改保存等命令时，旧的桌面菜单加速键让出，菜单点击入口继续工作。恢复默认后旧键位重新生效。 |
| 组合键冲突 | 设置中应提示冲突动作或系统保留键，并阻止保存。测试 `Mod+S`、`Mod+C`、`F3`、`Mod+Enter` 和 `Shift+F10`，并核对同一平台下 `Mod` 与 `Ctrl` 或 `Cmd` 的等价写法。 |
| 录制和输入 | 录制单个功能键或带修饰键的组合键，禁止会妨碍正常输入和选择的单键或仅 `Shift` 的普通键组合。`Esc` 取消此次更改，输入法组合键和 AltGr 字符继续输入。 |
| 旧版本设置与重启 | 保留已存的有效自定义值。旧值与新默认键重合时，优先执行已有自定义命令，设置页标明占用默认键的动作。恢复该命令默认值后，新默认键可重新使用。重开应用核对设置和命令面板显示的有效键位。 |
